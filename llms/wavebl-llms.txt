# WaveBL

> WaveBL is a digital trade platform for original electronic bills of lading (eBLs) and the trade
> documents around them, moving title between ocean carriers, freight forwarders, cargo owners,
> customs brokers and banks over a blockchain-backed peer-to-peer network with no central document
> repository. Headquartered in Kfar Saba, Israel.

Generated by API Evangelist from apis.yml and the artifacts in this repository on 2026-09-04.
Method: generated — WaveBL publishes no llms.txt of its own (https://wavebl.com/llms.txt returns 404).

## What an agent can and cannot do here

- WaveBL operates no developer portal and no API reference.
- No OpenAPI, AsyncAPI, GraphQL SDL, Protobuf or WSDL contract is published by WaveBL anywhere.
- WaveBL states that its platform "fully complies with 'DCSA OpenAPI specification for Issuance'
  and 'DCSA EBL Surrender Response API'" and points integrators at https://developer.dcsa.org/ebl.
  Those specifications are published by DCSA, not by WaveBL; the endpoints that implement them are
  provisioned per partner and are not public.
- There is no MCP server, no A2A agent card, no SDK in any package registry and no CLI.
- One WaveBL-owned API surface is reachable but undocumented:
  https://coa.wavebl.com/coadocuments (POST search, POST verify) behind the public Certificate of
  Authenticity verification tool.

## Notes for agents

- support.wavebl.com (the former Zendesk help centre, which carried the only public API article)
  is decommissioned and now fails the TLS handshake. Do not link users to it.
- docs.wavebl.com is not a documentation host — it is a CloudFront/S3 origin that has only ever
  served WaveBL's legal documents, and it returns 403 for every path today.
